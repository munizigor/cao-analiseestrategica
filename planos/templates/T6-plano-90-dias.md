## Parte D — E se a meta não for atingida?

| | **Ação CORRETIVA** | **Ação PREVENTIVA** |
|---|---|---|
| **Dispara quando** | o desvio **já ocorreu** | o desvio **ainda não ocorreu**, mas a tendência aponta para ele |
| **Atua sobre** | a causa do que aconteceu | a causa do que pode acontecer |
| **Sinal que a aciona** | indicador *lagging* fora da meta | indicador *leading* piorando |
| **No nosso caso, será:** | | |
| **Quem aciona:** | | |
| **Em quanto tempo:** | | |

**Gatilho numérico explícito:**

> Se o indicador ______________ atingir ______________ por ______ períodos consecutivos, então
> ______________________________________________.

> É isso que fecha o ciclo **PDCA**: o painel não serve para explicar o passado — serve para acionar
> as duas ações acima.
